## Método (o mesmo do curso)

1. Ler `docs/en.md` da lição e explicar a ideia com minhas palavras em `notas.md`.
2. Digitar o código importante, sem copiar e colar.
3. Rodar e guardar a evidência: comando, saída e o que mudei.
4. Só avançar quando conseguir explicar o resultado e fazer uma pequena alteração.
